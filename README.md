## api_yamdb
REST API для сервиса отзывов о произведениях искусства (фильмы, книги, музыка). Проект разработан в рамках обучения на платформе Яндекс Практикум.

## Функциональность модуля авторизации и пользователей

Все запросы к API выполняются через префикс: (`/api/v1/`)

Реализованный функционал:
-   Аутентификация и пользователи
-   Регистрация пользователей по email.
-   Получение кода подтверждения.
-   Получение JWT-токена.
-   Управление собственным профилем.
-   Управление пользователями через административные эндпоинты.
-   Поиск пользователей по username.
-   Ролевая модель доступа.

`Категории`
-   Получение списка категорий.
-   Создание категорий администраторами.
-   Удаление категорий администраторами.

`Жанры`
-   Получение списка жанров.
-   Создание жанров администраторами.
-   Удаление жанров администраторами.
-   Произведения
-   Получение списка произведений.
-   Фильтрация по:
-   категории;
-   жанру;
-   названию;
-   году выпуска.
-   Получение информации о произведении.
-   Создание произведений администраторами.
-   Редактирование произведений администраторами.
-   Удаление произведений администраторами.
-   Автоматический расчёт рейтинга произведения.

`Отзывы`
-   Просмотр отзывов.
-   Создание отзывов авторизованными пользователями.
-   Один пользователь может оставить только один отзыв на произведение.
-   Редактирование и удаление отзывов автором, модератором или администратором.

`Комментарии`
-   Просмотр комментариев к отзывам.
-   Создание комментариев авторизованными пользователями.
-   Редактирование и удаление комментариев автором, модератором или администратором.

## Пользовательские роли

`Аноним`:

-   Может просматривать произведения, отзывы и комментарии.

`Пользователь (user)` может:

-   читать информацию о произведениях;
-   публиковать отзывы;
-   выставлять оценки произведениям;
-   комментировать отзывы;
-   редактировать и удалять собственные отзывы и комментарии.
Роль назначается по умолчанию всем новым пользователям.

`Модератор (moderator)`:

-   Обладает всеми правами пользователя и может удалять любые отзывы и комментарии.

`Администратор (admin)`:

Обладает полными правами на управление проектом:

-   управление произведениями;
-   управление категориями;
-   управление жанрами;
-   управление пользователями;
-   назначение ролей.

`Суперпользователь Django`:

-   Имеет права администратора.

## Технологии

-   Python 3.14
-   Django 5.1.1
-   Django REST Framework 3.15.1
-   SimpleJWT (аутентификация)
-   drf-nested-routers (маршрутизация)
-   SQLite (база данных для разработки)

## Установка и запуск

1.  Клонируйте репозиторий и перейдите в папку проекта:
    ```bash
    git clone https://github.com/Seebyeof/api-yamdb.git
    cd api-yamdb
    ```

2.  Создайте и активируйте виртуальное окружение:
    ```bash
    python -m venv venv
    source venv/Scripts/activate
    ```

3.  Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```


4.  Примените миграции :
    ```bash
    python manage.py migrate
    ```

5. Загрузите тестовые данные:

    ```bash
    python manage.py import_csv
    ```

6. Запустите сервер:
    ```bash
    python manage.py runserver
    ```

## Документация API

После запуска сервера документация доступна по адресу `http://127.0.0.1:8000/redoc/`

## Основные эндпоинты
`Авторизация`
-   POST /api/v1/auth/signup/
-   POST /api/v1/auth/token/

`Пользователи`
-   GET /api/v1/users/
-   POST /api/v1/users/
-   GET /api/v1/users/{username}/
-   PATCH /api/v1/users/{username}/
-   DELETE /api/v1/users/{username}/
-   GET /api/v1/users/me/
-   PATCH /api/v1/users/me/

`Категории`
-   GET /api/v1/categories/
-   POST /api/v1/categories/
-   DELETE /api/v1/categories/{slug}/

`Жанры`
-   GET /api/v1/genres/
-   POST /api/v1/genres/
-   DELETE /api/v1/genres/{slug}/

`Произведения`
-   GET /api/v1/titles/
-   POST /api/v1/titles/
-   GET /api/v1/titles/{titles_id}/
-   PATCH /api/v1/titles/{titles_id}/
-   DELETE /api/v1/titles/{titles_id}/

`Отзывы`
-   GET /api/v1/titles/{title_id}/reviews/
-   POST /api/v1/titles/{title_id}/reviews/
-   GET /api/v1/titles/{title_id}/reviews/{review_id}/
-   PATCH /api/v1/titles/{title_id}/reviews/{review_id}/
-   DELETE /api/v1/titles/{title_id}/reviews/{review_id}/

`Комментарии`
-    GET /api/v1/titles/{title_id}/reviews/{review_id}/comments/
-   POST /api/v1/titles/{title_id}/reviews/{review_id}/comments/
-   GET /api/v1/titles/{title_id}/reviews/{review_id}/comments/{comment_id}/
-   PATCH /api/v1/titles/{title_id}/reviews/{review_id}/comments/{comment_id}/
-   DELETE /api/v1/titles/{title_id}/reviews/{review_id}/comments/{comment_id}/
