## api_yamdb
REST API для сервиса отзывов о произведениях искусства (фильмы, книги, музыка). Проект разработан в рамках обучения на платформе Яндекс Практикум.

## Функциональность модуля авторизации и пользователей

Данный репозиторий содержит реализацию системы аутентификации и управления пользователями:

-   **Регистрация**: Создание аккаунта через email с отправкой кода подтверждения (код выводится в консоль сервера при разработке).
-   **Аутентификация**: Получение JWT-токена по имени пользователя и коду подтверждения.
-   **Управление профилем**: Просмотр и редактирование собственного профиля (`/api/v1/users/me/`). Роль пользователя защищена от изменения.
-   **Администрирование**: Полный CRUD для управления пользователями (`/api/v1/users/`) доступен только администраторам. Поддерживается пагинация и поиск по username.
-   **Ролевая модель**: Три роли — `user`, `moderator`, `admin`. Разграничение прав доступа реализовано через кастомные permissions.

## Технологии

-   Python 3.14
-   Django 5.1.1
-   Django REST Framework 3.15.1
-   SimpleJWT (аутентификация)
-   drf-nested-routers (маршрутизация)
-   SQLite (база данных для разработки)

## Установка и запуск

1.  Клонируйте репозиторий и перейдите в папку проекта:
    ```bash
    git clone https://github.com/Seebyeof/api-yamdb.git
    cd api-yamdb
    ```

2.  Создайте и активируйте виртуальное окружение:
    ```bash
    python -m venv venv
    source venv/Scripts/activate
    ```

3.  Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```

4.  Примените миграции и запустите сервер:
    ```bash
    python manage.py migrate
    python manage.py runserver
    ```
